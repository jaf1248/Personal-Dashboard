# Personal Dashboard

This is a simple, elegant personal dashboard mock-up you can run without coding.

## How to use

1. Unzip the folder.
2. Double-click `index.html`.
3. It opens in your browser.

## Files

- `index.html` — dashboard content
- `styles.css` — visual design
- `script.js` — small date script

## Easy edits

Open `index.html` in Notepad/TextEdit/VS Code and change the placeholder events, task, headlines, health stats, weather, or traffic.
